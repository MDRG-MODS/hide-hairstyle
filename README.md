A utility modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** that enables selectively hiding parts of the robot companion's original hairstyle (front, side, back) to ensure flawless compatibility when equipping custom hairstyle mods.

---

## 🎮 Features

- **Selective Hair Layer Hiding:** Modular boolean toggles for:
  - Front Hair (`正面`)
  - Side Hair (`侧面`)
  - Back Hair (`背面`)
- Prevents texture clipping and overlap when wearing custom hairstyles.
- Color palette support for primary and secondary shades.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.90.7`).

> [!TIP]
> If you are using eyebrow mods alongside hair mods, make sure the order of **Hide Hairstyle** in the equipment bar is placed **above** the eyebrows!

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/hide-hairstyle/releases) page and download `Hide Hairstyle.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Hide Hairstyle.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Hide Hairstyle/mod.json
   ```
4. Launch the game and equip the module from your inventory.
