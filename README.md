A utility modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** that enables selectively hiding parts of the robot companion's original hairstyle (front, side, back) to ensure flawless compatibility when equipping custom hairstyle mods.

---

## 🎮 Features

- **Selective Hair Layer Hiding:** Modular boolean toggles for Front (`正面`), Side (`侧面`), and Back (`背面`).
- Prevents texture clipping and overlap when wearing custom hairstyles.
- Compatible with MDRG version **v0.97.12** (Target: `0.90.7`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/hide-hairstyle/releases) tab.
